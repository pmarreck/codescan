# Staged dependency parser interoperability

The shared `git-dependency-portability-gate` rejected an unchanged runtime Zig cache default in `flake.nix` as a dependency on `/.cache/zig`. Inspection of its `nix_tokens` function found that it ends an indented string at the first pair of single quotes, including the valid escaped shell interpolation prefix `''${`. It then interprets part of the shell string as a Nix path.

The rejection was reproduced by the actual pre-commit hook. The project uses an equivalent double-quoted Nix shell string now. The existing cache inheritance/default tests pass, and the real staged gate passes without an override. All five sandboxed release builds use the same declared source inputs; runtime cache defaults are not dependency sources.

The shared parser still needs a regression for escaped interpolation in indented strings, including nested quoting and ordinary runtime paths. Its eventual fix must retain rejection controls for actual host-local dependency declarations. The approved fix request was delivered through a durable inbox and the recipient's native application channel on October 28. The owning agent acknowledged acceptance at 00:25 EDT and committed to failing-first disposable-repository gate regressions while retaining unsafe-path and staged/worktree controls. Its fix commit and validation evidence remain pending; no hook change or bypass was made here.

The owning project reported the repair in commit `9c935fb` at 02:03 EDT. Its iterative lexer tracks indented strings, ordinary strings, and nested interpolation. Reported RED controls were four failures out of 95, followed by one nested-interpolation failure out of 96. Reported final validation passed all 96 focused controls, including real disposable commits and both staged/worktree disagreement directions, all 197 host test files, and the sandboxed Nix check. Codescan's remaining verification is to exercise the original runtime-cache interpolation through the installed repaired gate in a disposable consumer fixture, retaining an unsafe dependency rejection control. That consumer check has not run yet. No shared-hook change or bypass was made from this project.
