Both adapters reduced the existing index from four symbols/four code vectors/two comment vectors to one symbol/no vectors before reporting failure. This is a controlled data-preservation bug, independent of the historical watcher incident: both adapters recreated the database before the actual embedding probe, then substituted the configured width when that probe failed.

The change moves the actual probe before database replacement and rejects unusable embeddings with explicit unchanged-index advice. Deliberately accepted lexical-only indexing remains exempt. The real-adapter regression compares symbol rows and vector counts, checks that the MCP session continues after rejection, and subsequently requires lexical search and file reads.
